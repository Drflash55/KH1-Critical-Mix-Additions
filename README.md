# Kingdom Hearts I: Final Mix — Critical Mix Additions
Adds various amounts of additions courtesy of the Critical Mix mod:
- Animation Cancel
- Chain Attack Reaction Commands
- Finishing Magic Buff
- Item Auto Reload
- R2 Quick Items
- and Spirit Link
##
### IMPORTANT:
- Chain Attack Reaction Commands has issues with certain cutscenes playing in the game.
Though I have done my best to mitigate the problems, KH1FM will still have a likely chance
of crashing when transitioning back to Sora from a cutscene taking place in another "world".
- To mitigate this, it's recommended to temporarily disable the Chain Attack Reaction Commands
mod by renaming the `CMix_ChainAttackReactionCommand.lua` file to `CMix_ChainAttackReactionCommand.lua.bak`
and reloading the scripts by pressing `F1`. Then when you're past the scenes that do crash your game,
rename it back and then reload the file again.
- As a note, do save your game regularly so that you don't lose progress. I'll continue to try to find
a way to fix this issue, but KH1FM has had regular crashing problems just with the Keyboard/Mouse
input, so don't expect any miracles.
